# ちびっことのふれあいイベント - Fluffy -

GitHub Pages 向けの静的ホームページです。

## 公開前に差し替える場所

- `index.html` 内の Google Forms リンク。現在は公式Xで確認できた `https://forms.gle/xpqVGGZ8pLFVQG` を設定しています。
- 開催日時や集合方法が確定した場合は、`開催情報` セクションの文言
- キャスト名や個別プロフィールを載せる場合は、`キャスト紹介` セクション

## GitHub Pages

リポジトリにこのファイル一式を置き、GitHub の `Settings > Pages` から公開ブランチを選択してください。
